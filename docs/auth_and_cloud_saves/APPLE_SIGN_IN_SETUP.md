# Stato Sign in with Apple

Apple OAuth è intenzionalmente disabilitato e mostrato come “Prossimamente”.
Il repository non contiene ancora Team ID, Services ID o client secret. Il
callback nativo definitivo `com.mich.oculum://login-callback` è già registrato
su Android, iOS e macOS e deve essere autorizzato anche nella dashboard
Supabase quando il provider Apple verrà attivato.
