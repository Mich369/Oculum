# Configurazione piattaforme

Identificativo applicazione corrente: `com.mich.oculum`.

- Android: namespace e application ID `com.mich.oculum`.
- iOS: bundle identifier `com.mich.oculum`.
- macOS: bundle identifier `com.mich.oculum`.
- Linux: application ID `com.mich.oculum`.

Google e Apple OAuth non sono ancora configurati. Non sono presenti URL type,
intent filter, protocolli Windows o redirect OAuth provvisori. Questi elementi
andranno aggiunti insieme quando saranno disponibili gli identificativi e gli
URL definitivi.
